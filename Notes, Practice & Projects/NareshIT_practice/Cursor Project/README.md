# 3D Airplane Simulation Game

A simple 3D airplane simulation game built with Three.js that runs in your web browser.

## Features

- **Realistic 3D Airplane**: Detailed airplane model with fuselage, wings, tail, cockpit, and propeller
- **Physics Simulation**: Realistic flight physics including gravity, velocity, and collision detection
- **Interactive Controls**: Full flight controls for pitch, roll, yaw, and throttle
- **Beautiful Environment**: 3D terrain with mountains, animated clouds, and atmospheric fog
- **Real-time UI**: Live speedometer and altitude display
- **Responsive Design**: Works on different screen sizes

## How to Run

1. Simply open `index.html` in your web browser
2. The game will start automatically
3. No additional setup or installation required

## Controls

- **W/S**: Pitch Up/Down (nose up/down)
- **A/D**: Roll Left/Right (banking)
- **Q/E**: Yaw Left/Right (turning)
- **↑/↓**: Throttle Up/Down (speed control)
- **Space**: Reset Position (return to starting position)

## Tips for Flying

1. Start by increasing throttle (↑) to gain speed
2. Use W/S to control pitch and gain/lose altitude
3. Use A/D for banking turns
4. Use Q/E for coordinated turns
5. Keep an eye on your speed and altitude
6. Press Space to reset if you get lost

Enjoy flying! 🛩️
